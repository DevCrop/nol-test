# 블루스퀘어 메뉴별 권한 증분

운영 적용 전 최신 DB 사본에서 검증한다. 원본 덤프로 운영 DB를 덮어쓰지 않는다.

1. 기존 보안 스키마와 `UPGRADE-20261027.md`의 임시 비밀번호·InnoDB·권한기간 적용 여부를 확인한다.
2. `sql/manual/admin-menu-permissions-20261105.sql` 실행. 반복 실행 가능하며 비밀번호를 변경하지 않는다.
3. 기존 활성 일반 관리자 전원의 메뉴별 조회·생성·수정·삭제 권한을 확정한다. NULL/잘못된 권한은 차단한다. 최고관리자는 전체 권한을 유지한다.
4. 승인된 신규 계정 SQL을 비공개 인계 폴더에서 가져와 전체 실행한다. 오류 시 즉시 중단·ROLLBACK. 기존 정보와 충돌하면 덮어쓰지 않고 확인한다.
5. 기존 환경/업로드를 보존하며 새 웹 코드를 반영한다. preflight가 활성 일반 관리자의 권한 누락을 발견하면 진행을 중지한다.
6. 임시 비밀번호는 운영 SQL 실행 시점부터 기본 24시간 유효하다. 안전한 경로로 전달하고 만료 시 재발급한다.
7. 로그인 → MFA → 임시 비밀번호 강제 변경 → 허용 메뉴 진입, 비허용 직접 접근 차단, 본인 비밀번호 변경을 확인한다.

연락처는 필수항목이 아니다. 권한 변경 시 기존 로그인 세션과 진행 중 MFA의 권한 정보는 무효화한다. 권한기간은 승인된 값으로 설정한다.

고객 개인정보·비밀번호·운영 DB는 GitHub/웹 ZIP에 포함하지 않는다. 새 권한 기능을 포함한 최종 배포본은 다시 생성해야 한다. 이 안내는 운영 적용 완료를 의미하지 않는다.
