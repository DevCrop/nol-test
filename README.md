# NOL Theater and BlueSquare security review workspaces

두 프로젝트의 260918 작업본입니다.

- 저장소 루트: 블루스퀘어 (기존 경로 유지)
- [놀씨어터/260918](놀씨어터/260918/): 놀씨어터 독립 프로젝트

프로젝트별 Docker, 환경설정, 체크리스트, QA 및 증분 SQL을 각각 사용하세요. 놀씨어터에도 동일하게 비밀값·원본 DB·고객 업로드 자료 제외 기준을 적용했습니다. 이번 놀씨어터 추가는 업로드 작업이며 보안 QA를 새로 수행했다는 의미는 아닙니다.

공개용 놀씨어터 복사본은 DB 비밀번호 기본값을 제거했습니다. 실제 값은 로컬 환경설정으로만 제공해야 합니다.

보안 조치 범위, 실제 QA 결과 및 미완료 항목은 [취약점 체크리스트](취약점_체크리스트.md)를 확인하세요. 이 저장소가 모든 진단 항목의 최종 완료나 운영 배포 승인을 의미하지는 않습니다.

## 실행 준비

1. `.env.example`을 로컬 `.env`로 복사하고 프로젝트 전용 DB/SMTP 값을 설정합니다.
2. 원본 `260918.sql`과 필요한 업로드/다운로드 자료는 승인된 별도 경로에서 받아 복원합니다.
3. [환경설정](환경설정.md)과 [운영배포](운영배포.md)를 따라 Docker 및 마이그레이션을 준비합니다.

비밀번호가 들어 있는 환경 파일, 원본 DB 덤프, 고객 업로드 자료, 로그, 브라우저 프로필 및 QA 스크린샷은 공개 저장소에 포함하지 않습니다. 증분 스키마 SQL과 QA 실행 코드는 포함합니다. 원본 덤프가 없는 상태에서는 초기 적재 및 덤프 기반 QA를 실행할 수 없습니다.
