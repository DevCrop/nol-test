# 놀씨어터 — 보안 보완 및 로컬 QA

이 브랜치는 놀씨어터의 독립 소스 루트입니다. 저장소 브랜치: `codex/nol-security`.
다른 프로젝트는 별도 브랜치로 관리하며 실행 중 다른 프로젝트 파일을 참조하지 않습니다.

## 시작 전

1. `.env.example`을 참고하여 로컬 `.env`를 작성합니다. 실제 비밀번호·SMTP 값은 커밋하지 않습니다.
2. 승인된 경로로 받은 원본 `260918.sql`을 루트에 별도로 준비합니다. 개인정보 포함 덤프는 저장소에 없습니다.
3. [환경설정.md](환경설정.md)의 Docker 구성을 사용합니다. 공개 주소는 `http://localhost:8618/`, 관리자 주소는 `http://gate.local:8618/`입니다. 로컬 hosts의 gate.local 연결이 필요합니다.
4. 운영 DB는 초기 덤프로 덮어쓰지 않습니다. [운영배포.md](운영배포.md)에 따라 백업 후 증분 `sql/release.php check` 및 `up`을 적용합니다.

- [최종 QA 실행 기록](QA_최종검증_20260928.md)
- [고객 진단·정책 체크리스트](취약점_체크리스트.md)
- [작업 기록](작업기록.md)

자동 QA에는 합성 DB 변경 검사가 포함되므로 운영에서 실행하지 않습니다. 전체 CRUD 검사는 `qa/compose.clean.yml`의 별도 QA DB(`qa_app`)에서 수행합니다. 개발 DB의 검사는 일부 항목을 SKIP하므로 같은 완료 수치로 해석하면 안 됩니다.

현재 검증 결과는 **운영 승인이나 고객 요구 전체 전수 완료 판정이 아닙니다.** 구형 기능 사용 범위, 실제 SMTP 및 운영 도메인/IP/HTTPS 등 남은 항목은 체크리스트를 확인하세요.

원본 덤프·고객 PDF·업로드·실제 세션/로그·비밀값과 로컬 QA 스크린샷은 게시 대상이 아닙니다. 공개 가능한 코드·증분 스키마·테스트·요약 기록만 보관합니다.
