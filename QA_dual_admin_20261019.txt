최신 지침: gate와 기존 관리자 경로 동시 운영 (자동 우회 취소)

현재 요구 및 구현
- 기존 https://noltheater-daehakro.com/nol-gate/ 사용 가능.
- http://gate.noltheater-daehakro.com/ 및 인증서 설치된 https://gate.noltheater-daehakro.com/도 관리자 루트 제공.
- GATE_ALLOW_LEGACY_ADMIN=true로 기존 정확한 PUBLIC_HOST의 HTTPS 관리자 경로만 임시 허용.
- GATE_ALLOW_HTTP=true는 정확한 gate 호스트에만 적용. 기존 공개 홈페이지 HTTPS 유지.
- SSL 유효성 자동 감지/우회 로직은 제거. 앞서 전달한 fallback ZIP은 사용하지 않음.
- IP/MFA/CSRF/권한/동시접속/30분 유휴 세션 유지. GATE_ENFORCE=true, SESSION_SECURE=true 유지.
- 서로 다른 호스트는 별도 쿠키로 로그인하며 같은 계정 새 로그인은 기존 세션을 종료함.
