## 결정

- 관리자 쓰기는 REST가 아니다. GATE 같은 호스트에서 `POST` + `mode` + 세션 쿠키.
- 공개 사이트는 GATE API를 부르지 않는다.
- 세션 쿠키는 **호스트 전용**. `SESSION_DOMAIN` 비움. 부모 도메인에 찍지 않음.
- `fetcher`는 `credentials: "include"`, body는 **FormData** (JSON이면 PHP `$_POST`가 못 읽음).
- CORS `*` 금지. `CORS_ORIGINS` 화이트리스트만.
- 비밀은 `.env`만. git·`setup.php`·감사 JSON에 비밀번호/SMTP/`login_token` 넣지 않음.
- Compose에는 DB 기본 비밀번호를 두지 않고 `DB_NAME`, `DB_USER`, `DB_PASS`, `DB_ROOT_PASSWORD`를 필수값으로 검사.
- 가비아가 서브도메인 가능하다고 말한 것으로 단정하지 않음. DNS는 아사달 A레코드.
- 일반관리자도 계정 생성 때 준 ACL로 글을 고친다. CRUD 로그(26)는 **성공한 쓰기면 누구나** 남기고, 목록은 최고만.
- 26은 계정·권한만이 아니라 게시/배너 등 성공한 CUD 전부(요청에 따라 확장). 본인 `pwd.change`는 제외.
- 21은 26과 다름. 개인정보 **열람/다운로드**. 접속 통계 메뉴는 공개 트래픽.
- 32 Drag&Copy는 점검용 UI 제한. 개발자 도구·스크린샷은 막지 않음.

## 구조

스택: PHP 7.4 Apache + MySQL 8.0. 관리자 폴더 `nol-gate`.

| 호스트 | 역할 |
| --- | --- |
| `PUBLIC_HOST` | 공개. 문서루트 프로젝트 루트. 이미지 `/uploads/...` |
| `GATE_HOST` | 관리자. 문서루트 `nol-gate`. 로컬 `http://gate.local:8618` |

`GATE_ENFORCE=true` 이고 `GATE_HOST`가 있으면 공개 호스트 `/nol-gate` → **404**(리다이렉트 없음).

GATE Apache는 `/uploads`를 프로젝트 `uploads`에 Alias. DB에는 파일명 또는 `/uploads/banners/...` 상대 경로만. 공개 화면은 `공개도메인/uploads/...`. 수정은 GATE POST.

### 로그인 파이프라인

1. 캡차 → 아이디/비번  
2. 실패 5회 / 15분 잠금 (`login.process`)  
3. `active_status=N` 거부  
4. `AccountIdleLock::guard` (90일, 마지막 살아 있는 최고는 자동 잠금 안 함)  
5. MFA 켜져 있으면 메일 6자리 (`nb_admin.email` 없으면 발송 안 됨. MFA 테이블 없음)  
6. `AuthSession::establish` — `session_regenerate_id`, `login_token` later-wins, `last_login_at`  
7. `PasswordChangeGate` — 초기화 강제(29) 또는 90일 만료(28)면 `/pages/setting/pwd.php`

이후 매 요청: 동시접속 토큰 → 비번 게이트 → ACL.

401(`denyLogin`)만 세션을 비우고 GATE `index.php`. 403·비번 강제는 로그인으로 안 던짐.

HTML 화면의 401은 서버 리다이렉트 후 로그인 화면의 세션 플래시만 한 번 표시한다. 헤더 전송이 끝난 예외 상황에서만 자바스크립트 폴백을 사용한다.

### 쿠키

`NOLGATESESSID`, HttpOnly, SameSite=Lax, Secure는 HTTPS에서 true. 로그아웃 `setcookie`도 같은 옵션으로 만료.

## 운영에서 할 일 (코드 밖)

1. 아사달 A → 가비아 IP. GATE 호스트 SSL. 문서루트 `nol-gate`.  
2. `.env` 운영 값. `GATE_ENFORCE`는 로그인 확인 전 `false`.  
3. `license.php`에 운영 Host 해시.  
4. `php sql/migrate.php up`.  
5. GATE 로그인 확인 → `GATE_ENFORCE=true` → 공개 `/nol-gate` 404.  
6. SMTP 되면 `MFA_ENABLED=true`.  
7. 고객 IP가 오면 `GATE_ALLOW_IPS` 채움. `qa/gate_allowlist.php`로 등록/미등록 IP를 확인. 비우면 아무 IP나 GATE 가능.

로컬: `make up`, `make db-import`, hosts `127.0.0.1 gate.local`.

## 사용자 흐름 (관리자)

1. GATE 주소로 로그인(캡차).  
2. MFA면 메일 숫자 입력. 발송·확인 중에는 전역 로딩이 표시되고 인증 유효시간이 초 단위로 보인다.  
3. 미접속 잠금이면 최고가 계정 화면에서 해제.  
4. 비번 강제/만료면 변경 화면만. 끝나면 다시 로그인.  
5. 다른 곳에서 같은 ID로 로그인하면 이전 세션 끊김.  
6. 대관 목록은 이름 마스킹 및 드래그/복사 차단. 상세 열면 접속기록. 파일은 사유 후 다운로드. 상세도 드래그/복사 안 됨.  
7. 글·배너 등 저장/삭제는 작업 이력. 개인정보 열람은 접속기록.  
8. 상단 `자동 로그아웃`은 `30:00`부터 감소하며 실제 사용자 활동 시 서버 세션과 함께 다시 `30:00`으로 갱신된다.
