## 로컬

| 용도 | 주소 |
| --- | --- |
| 공개 | http://localhost:8618 |
| 관리자 폴더 | http://localhost:8618/nol-gate |
| 관리자 GATE | http://gate.local:8618 |

```
make up
make db-import
make up-tools
make down
```

Compose 프로젝트가 `260918`이면 `docker compose -p 260918 up -d --build web`.

## `.env`

| 키 | 로컬 | 운영 |
| --- | --- | --- |
| `APP_ENV` | `development` | `production` |
| `PUBLIC_HOST` | 공개 호스트 | 예 `noltheater-daehakro.com` (스킴·포트 없음) |
| `GATE_HOST` | `gate.local` | 예 `gate.noltheater-daehakro.com` (스킴·포트 없음) |
| `GATE_ENFORCE` | `true` | GATE 확인 전 `false` → 확인 후 `true`. 안 열리면 즉시 `false` |
| `CORS_ORIGINS` | `http://localhost:8618,http://gate.local:8618` | `https://공개,https://GATE`. `*` 금지 |
| `SESSION_NAME` | `NOLGATESESSID` | 그대로 |
| `SESSION_DOMAIN` | 비움 | **비움.** 부모 도메인 금지 |
| `SESSION_SECURE` | `false` | HTTPS면 `true` |
| `SESSION_SAMESITE` | `Lax` | `Lax` |
| `MFA_ENABLED` | 시험만 `true` | SMTP 확인 전 `false` → 후 `true` |
| `SMTP_*` | `.env`만 | 구글 계정 + 앱 비밀번호. 그룹메일 불가 |
| `DB_*` | 도커 | 가비아 |
| `ACCOUNT_IDLE_DAYS` | `90` | 계약과 같으면 그대로 |
| `PASSWORD_MAX_DAYS` | `90` | 계약과 같으면 그대로 |
| `GATE_ALLOW_IPS` | 비움 | 운영 사무실 CIDR. 비면 제한 없음. GATE 호스트(+남은 `/nol-gate`)만 적용 |

`GATE_ENFORCE=true`: 공개 호스트 `/nol-gate` → 404 (리다이렉트 없음). `GATE_HOST`가 비면 안 막힌다.  
정적 파일까지 404면 루트 `.htaccess` `# SetEnv GATE_ENFORCE true` 주석 해제.

`GATE_ALLOW_IPS`는 단일 IP와 IPv4 CIDR을 콤마로 등록한다. `qa/gate_allowlist.php`가 등록 IP 허용과 미등록 IP 차단을 검사한다.

`SESSION_LIFETIME`은 쿠키 수명과 관리자 무활동 자동 로그아웃 기준으로 함께 사용한다. 마지막 관리자 요청 이후 이 시간이 지나면 로그인 화면으로 이동한다.

## 실서버 (코드 안 바꾸고 이것만)

DNS A레코드(아사달) → 가비아 IP, GATE 호스트 SSL, 문서루트 `nol-gate`.  
가비아 유료 「도메인 연결」은 A레코드와 다름.

`.env` 예:

```
APP_ENV=production
PUBLIC_HOST=noltheater-daehakro.com
GATE_HOST=gate.noltheater-daehakro.com
GATE_ENFORCE=false
CORS_ORIGINS=https://noltheater-daehakro.com,https://gate.noltheater-daehakro.com
SESSION_SECURE=true
SESSION_DOMAIN=
MFA_ENABLED=false
```

1. `inc/lib/license.php`에 운영 `HTTP_HOST` 해시 (GATE·공개 각각). `development`는 통과.
2. 서버에서 `php sql/migrate.php up` (`nb_admin_acl`, 로그인 토큰, 미접속, 비번 플래그/변경일, `nb_admin_audit`, `nb_admin_privacy_access`).
3. `https://GATE_HOST/` 로그인 → 캡차 → (MFA면) 메일 → 게시판. 저장은 같은 호스트 POST+쿠키.
4. 되면 `GATE_ENFORCE=true`. 공개 `/nol-gate` 404 확인. SMTP 되면 `MFA_ENABLED=true`.

건드리지 말 것: `SESSION_DOMAIN`, `fetcher`/`API.*` 경로, `$_POST`+`mode`, CORS `*`.

## MFA

아이디/비번/캡차 → 이메일 → 6자리 → 세션. 테이블 없음. `nb_admin.email` 없는 계정은 발송 안 됨.

`MFA_TTL_SECONDS=900`, 시도 5회, 재발송 30초.  
운영: SMTP 기입 → 메일 있는 계정 시험 → `MFA_ENABLED=true`. 시험 끝난 앱 비밀번호는 재발급.
